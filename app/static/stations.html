Stations

Switch stations on or off, rename and reorder them, and add new ones. Changes take effect within a few seconds. Switching a station off pauses polling but keeps its history. You can also add the same station twice under different names (for a Christmas-music version, say) and switch between them.

This server is read-only, so stations can be looked at here but not changed.

Add a station

Paste the station's web page and I'll find its feed: an iHeart page like washfm.iheart.com or iheart.com/live/…, or an Audacy page like audacy.com/kroq.

The feed is tested first, so adding takes a few seconds.

Delete this station?

This can't be undone. To keep a copy first, export it from Import / Export. If you only want it to stop polling, switch it off instead.
